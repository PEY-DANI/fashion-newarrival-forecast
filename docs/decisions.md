## D3. 수집 범위 — 일부 결정 (2026-10-07)

| 항목 | 결정 | 이유 |
|---|---|---|
| 카테고리 | **우선 반소매 티셔츠 1종만** (이후 상의로 확장 여부는 결과를 보고 판단) | 패션은 변수가 많아서 범위를 좁힌다. 한 카테고리로 먼저 해본다 |
| 성별 | **여성 + 공용** | 여성을 대상으로 하되 공용도 포함하는 게 맞다고 판단 |
| 등록일 | **27개월 전까지** (하한과 기준 정의는 아래 미정 항목) | |
| 카테고리별 브랜드 효과 | 수집 전에 미리 확인하지 않는다 | 그 차이 자체가 분석 결과로 쓸 수 있는 부분이기 때문 |

아직 정하지 않은 것:

- [ ] 등록일 하한(16주 창이 완성되는 112일?)과 27개월의 기준 정의, 등록일 출처(썸네일 URL / goodsCreateDate)
- [ ] 표본 선정 방식 (목록을 끝까지 훑을지)
- [ ] 예측 단위 (SKU / 스타일)
- [ ] 리뷰 구간 수 (4구간 유지 / 줄이기)
- [ ] 사진 조건 (수집 때 거르기 / 분석 때 처리)
